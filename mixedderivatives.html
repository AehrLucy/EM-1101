Mixed Derivative Practice Problems

logarithmic, exponential, hyperbolic, inverse trigonometric and inverse hyperbolic functions

Problem · 1–5One chain rule through two function types
Problem · 6–10Product rule, identities, simplification
Problem · 11–15Logarithmic and implicit differentiation, proofs

Formulas used

$$\frac{d}{dx}\ln u=\frac{u'}{u}\qquad \frac{d}{dx}e^{u}=e^{u}u'$$ $$\frac{d}{dx}\sinh u=\cosh u\,u'\qquad \frac{d}{dx}\cosh u=\sinh u\,u'$$ $$\frac{d}{dx}\tanh u=\operatorname{sech}^{2}u\,u'$$
$$\frac{d}{dx}\sin^{-1}u=\frac{u'}{\sqrt{1-u^{2}}}\qquad \frac{d}{dx}\tan^{-1}u=\frac{u'}{1+u^{2}}$$ $$\frac{d}{dx}\sinh^{-1}u=\frac{u'}{\sqrt{1+u^{2}}}\qquad \frac{d}{dx}\tanh^{-1}u=\frac{u'}{1-u^{2}}$$ $$\cosh^{2}x-\sinh^{2}x=1\qquad 1-\tanh^{2}x=\operatorname{sech}^{2}x$$

Level 1: Problems 1–5

Problem 1

LogarithmicHyperbolic

Find the derivative.

$$y=\ln(\cosh x)$$
Step-by-step solution
1

The outer function is the natural logarithm and the inner function is \(u=\cosh x\). Use the log rule.

$$\frac{dy}{dx}=\frac{u'}{u}$$
2

Differentiate the inner function.

$$u'=\frac{d}{dx}\cosh x=\sinh x$$
3

Substitute and simplify.

$$\frac{dy}{dx}=\frac{\sinh x}{\cosh x}=\tanh x$$
Answer
$$\frac{dy}{dx}=\tanh x$$

Problem 2

ExponentialInverse trig

Find the derivative.

$$y=e^{\tan^{-1}x}$$
Step-by-step solution
1

The outer function is the exponential and the inner function is \(u=\tan^{-1}x\).

$$\frac{dy}{dx}=e^{u}\,u'$$
2

Differentiate the inner function.

$$u'=\frac{1}{1+x^{2}}$$
3

Substitute.

$$\frac{dy}{dx}=e^{\tan^{-1}x}\cdot\frac{1}{1+x^{2}}$$
Answer
$$\frac{dy}{dx}=\frac{e^{\tan^{-1}x}}{1+x^{2}}$$

Problem 3

HyperbolicLogarithmicExponential

Find the derivative for \(x>0\) and write it without hyperbolic functions.

$$y=\sinh(\ln x)$$
Step-by-step solution
1

Apply the chain rule with \(u=\ln x\), so \(u'=\tfrac1x\).

$$\frac{dy}{dx}=\cosh(\ln x)\cdot\frac{1}{x}$$
2

Rewrite \(\cosh(\ln x)\) with the exponential definition of cosh.

$$\cosh(\ln x)=\frac{e^{\ln x}+e^{-\ln x}}{2}=\frac{x+\frac1x}{2}=\frac{x^{2}+1}{2x}$$
3

Substitute back.

$$\frac{dy}{dx}=\frac{x^{2}+1}{2x}\cdot\frac1x$$
Answer
$$\frac{dy}{dx}=\frac{x^{2}+1}{2x^{2}}$$

Problem 4

Inverse trigExponential

Find the derivative for \(x<0\).

$$y=\sin^{-1}\!\left(e^{x}\right)$$
Step-by-step solution
1

Use the inverse sine rule with \(u=e^{x}\).

$$\frac{dy}{dx}=\frac{u'}{\sqrt{1-u^{2}}}$$
2

Here \(u'=e^{x}\) and \(u^{2}=e^{2x}\).

$$\frac{dy}{dx}=\frac{e^{x}}{\sqrt{1-e^{2x}}}$$
Answer
$$\frac{dy}{dx}=\frac{e^{x}}{\sqrt{1-e^{2x}}}$$

The condition \(x<0\) keeps \(e^{x}<1\), so the square root is real and nonzero.

Problem 5

LogarithmicInverse trig

Find the derivative for \(x>0\).

$$y=\ln\!\left(\tan^{-1}x\right)$$
Step-by-step solution
1

Use the log rule with \(u=\tan^{-1}x\).

$$\frac{dy}{dx}=\frac{u'}{u}$$
2

Differentiate the inner function and substitute.

$$\frac{dy}{dx}=\frac{\dfrac{1}{1+x^{2}}}{\tan^{-1}x}$$
Answer
$$\frac{dy}{dx}=\frac{1}{\left(1+x^{2}\right)\tan^{-1}x}$$

Level 2: Problems 6–10

Problem 6

ExponentialHyperbolic

Find the derivative and express it in terms of \(\tanh x\) only.

$$y=e^{2x}\tanh x$$
Step-by-step solution
1

Use the product rule with these two factors.

$$f=e^{2x},\ \ f'=2e^{2x}\qquad g=\tanh x,\ \ g'=\operatorname{sech}^{2}x$$
2

Apply \((fg)'=f'g+fg'\) and factor.

$$\frac{dy}{dx}=2e^{2x}\tanh x+e^{2x}\operatorname{sech}^{2}x=e^{2x}\left(2\tanh x+\operatorname{sech}^{2}x\right)$$
3

Replace \(\operatorname{sech}^{2}x\) using \(\operatorname{sech}^{2}x=1-\tanh^{2}x\).

$$\frac{dy}{dx}=e^{2x}\left(1+2\tanh x-\tanh^{2}x\right)$$
Answer
$$\frac{dy}{dx}=e^{2x}\left(1+2\tanh x-\tanh^{2}x\right)$$

Problem 7

Inverse trigHyperbolic

Find the derivative and simplify to a single hyperbolic function.

$$y=\tan^{-1}(\sinh x)$$
Step-by-step solution
1

Use the inverse tangent rule with \(u=\sinh x\), so \(u'=\cosh x\).

$$\frac{dy}{dx}=\frac{\cosh x}{1+\sinh^{2}x}$$
2

From \(\cosh^{2}x-\sinh^{2}x=1\), the denominator equals \(\cosh^{2}x\).

$$\frac{dy}{dx}=\frac{\cosh x}{\cosh^{2}x}=\frac{1}{\cosh x}$$
Answer
$$\frac{dy}{dx}=\operatorname{sech}x$$

Problem 8

LogarithmicInverse hyperbolic

Find the derivative. What familiar function is \(y\)?

$$y=\ln\!\left(x+\sqrt{x^{2}+1}\right)$$
Step-by-step solution
1

Use the log rule with \(u=x+\sqrt{x^{2}+1}\).

$$\frac{dy}{dx}=\frac{u'}{u}$$
2

Differentiate the inside and combine over a common denominator.

$$u'=1+\frac{x}{\sqrt{x^{2}+1}}=\frac{\sqrt{x^{2}+1}+x}{\sqrt{x^{2}+1}}$$
3

Divide by \(u\). The factor \(x+\sqrt{x^{2}+1}\) cancels.

$$\frac{dy}{dx}=\frac{x+\sqrt{x^{2}+1}}{\sqrt{x^{2}+1}}\cdot\frac{1}{x+\sqrt{x^{2}+1}}=\frac{1}{\sqrt{x^{2}+1}}$$
Answer
$$\frac{dy}{dx}=\frac{1}{\sqrt{x^{2}+1}},\qquad y=\sinh^{-1}x$$

This is the derivative of \(\sinh^{-1}x\), and the logarithm is its standard closed form.

Problem 9

ExponentialInverse hyperbolic

Find the derivative.

$$y=e^{x}\sinh^{-1}x$$
Step-by-step solution
1

Use the product rule with these two factors.

$$f=e^{x},\ \ f'=e^{x}\qquad g=\sinh^{-1}x,\ \ g'=\frac{1}{\sqrt{1+x^{2}}}$$
2

Apply the product rule.

$$\frac{dy}{dx}=e^{x}\sinh^{-1}x+\frac{e^{x}}{\sqrt{1+x^{2}}}$$
Answer
$$\frac{dy}{dx}=e^{x}\left(\sinh^{-1}x+\frac{1}{\sqrt{1+x^{2}}}\right)$$

Problem 10

LogarithmicHyperbolic

Find the derivative for \(x>0\) and simplify to a single hyperbolic function.

$$y=\ln\!\left(\tanh\frac{x}{2}\right)$$
Step-by-step solution
1

Use the log rule, then the chain rule on \(\tanh\frac x2\).

$$\frac{dy}{dx}=\frac{\frac{d}{dx}\tanh\frac{x}{2}}{\tanh\frac{x}{2}}=\frac{\frac12\operatorname{sech}^{2}\frac{x}{2}}{\tanh\frac{x}{2}}$$
2

Write everything in sinh and cosh.

$$\frac{dy}{dx}=\frac12\cdot\frac{1}{\cosh^{2}\frac x2}\cdot\frac{\cosh\frac x2}{\sinh\frac x2}=\frac{1}{2\sinh\frac x2\cosh\frac x2}$$
3

Use the double-angle identity \(\sinh x=2\sinh\frac x2\cosh\frac x2\).

$$\frac{dy}{dx}=\frac{1}{\sinh x}$$
Answer
$$\frac{dy}{dx}=\operatorname{csch}x$$

Level 3: Problems 11–15

Problem 11

Logarithmic differentiationHyperbolicExponential

Find the derivative.

$$y=(\cosh x)^{x}$$
Step-by-step solution
1

Both the base and the exponent depend on \(x\). Take the natural logarithm of both sides. This is valid because \(\cosh x>0\).

$$\ln y=x\ln(\cosh x)$$
2

Differentiate both sides, using the product rule on the right and Problem 1 for \(\ln(\cosh x)\).

$$\frac{1}{y}\frac{dy}{dx}=\ln(\cosh x)+x\cdot\frac{\sinh x}{\cosh x}=\ln(\cosh x)+x\tanh x$$
3

Multiply by \(y\) and substitute \(y=(\cosh x)^{x}\).

$$\frac{dy}{dx}=y\left[\ln(\cosh x)+x\tanh x\right]$$
Answer
$$\frac{dy}{dx}=(\cosh x)^{x}\left[\ln(\cosh x)+x\tanh x\right]$$

Problem 12

Inverse trigHyperbolic

Find the derivative and simplify fully.

$$y=\tan^{-1}\!\left(\tanh\frac{x}{2}\right)$$
Step-by-step solution
1

Use the inverse tangent rule with \(u=\tanh\frac x2\), so \(u'=\frac12\operatorname{sech}^{2}\frac x2\).

$$\frac{dy}{dx}=\frac{\frac12\operatorname{sech}^{2}\frac{x}{2}}{1+\tanh^{2}\frac{x}{2}}$$
2

Multiply the numerator and denominator by \(\cosh^{2}\frac x2\).

$$\frac{dy}{dx}=\frac{1}{2}\cdot\frac{1}{\cosh^{2}\frac{x}{2}+\sinh^{2}\frac{x}{2}}$$
3

Use the identity \(\cosh^{2}t+\sinh^{2}t=\cosh 2t\) with \(t=\frac x2\).

$$\frac{dy}{dx}=\frac{1}{2\cosh x}$$
Answer
$$\frac{dy}{dx}=\frac12\operatorname{sech}x$$

Problem 13

Logarithmic differentiationInverse hyperbolic

Find the derivative for \(x>0\).

$$y=x^{\sinh^{-1}x}$$
Step-by-step solution
1

Take the natural logarithm of both sides.

$$\ln y=\sinh^{-1}x\cdot\ln x$$
2

Differentiate both sides with the product rule.

$$\frac{1}{y}\frac{dy}{dx}=\frac{\ln x}{\sqrt{1+x^{2}}}+\frac{\sinh^{-1}x}{x}$$
3

Multiply by \(y=x^{\sinh^{-1}x}\).

$$\frac{dy}{dx}=y\left(\frac{\ln x}{\sqrt{1+x^{2}}}+\frac{\sinh^{-1}x}{x}\right)$$
Answer
$$\frac{dy}{dx}=x^{\sinh^{-1}x}\left(\frac{\ln x}{\sqrt{1+x^{2}}}+\frac{\sinh^{-1}x}{x}\right)$$

Problem 14

Implicit differentiationExponentialInverse trigHyperbolic

Find \(\dfrac{dy}{dx}\), then find the tangent line at the origin.

$$e^{y}+\tan^{-1}(xy)=1+\sinh x$$
Step-by-step solution
1

Differentiate every term with respect to \(x\). The inverse tangent term needs the chain rule, and its inside \(xy\) needs the product rule.

$$e^{y}\frac{dy}{dx}+\frac{y+x\frac{dy}{dx}}{1+x^{2}y^{2}}=\cosh x$$
2

Multiply through by \(1+x^{2}y^{2}\) to clear the fraction.

$$e^{y}\left(1+x^{2}y^{2}\right)\frac{dy}{dx}+y+x\frac{dy}{dx}=\cosh x\left(1+x^{2}y^{2}\right)$$
3

Collect the \(\frac{dy}{dx}\) terms on the left.

$$\frac{dy}{dx}\left[e^{y}\left(1+x^{2}y^{2}\right)+x\right]=\cosh x\left(1+x^{2}y^{2}\right)-y$$
4

Solve for \(\frac{dy}{dx}\).

$$\frac{dy}{dx}=\frac{\cosh x\left(1+x^{2}y^{2}\right)-y}{e^{y}\left(1+x^{2}y^{2}\right)+x}$$
5

Check that the origin is on the curve, then evaluate the slope there.

$$e^{0}+\tan^{-1}0=1=1+\sinh 0\ \checkmark\qquad \left.\frac{dy}{dx}\right|_{(0,0)}=\frac{1\cdot1-0}{1\cdot1+0}=1$$
Answer
$$\frac{dy}{dx}=\frac{\cosh x\left(1+x^{2}y^{2}\right)-y}{e^{y}\left(1+x^{2}y^{2}\right)+x},\qquad \text{tangent at the origin: } y=x$$

Problem 15

ExponentialInverse hyperbolicSecond derivative

Let \(a\) be a constant. Prove that the function below satisfies the differential equation.

$$y=e^{a\sinh^{-1}x}\qquad\Longrightarrow\qquad \left(1+x^{2}\right)y''+xy'-a^{2}y=0$$
Step-by-step solution
1

Find the first derivative with the chain rule.

$$y'=e^{a\sinh^{-1}x}\cdot\frac{a}{\sqrt{1+x^{2}}}=\frac{ay}{\sqrt{1+x^{2}}}$$
2

Clear the root before differentiating again. This avoids a messy quotient rule.

$$\sqrt{1+x^{2}}\;y'=ay$$
3

Differentiate both sides with the product rule. On the right, substitute \(y'\) from Step 1.

$$\frac{x}{\sqrt{1+x^{2}}}\,y'+\sqrt{1+x^{2}}\;y''=ay'=\frac{a^{2}y}{\sqrt{1+x^{2}}}$$
4

Multiply every term by \(\sqrt{1+x^{2}}\) and rearrange.

$$xy'+\left(1+x^{2}\right)y''=a^{2}y$$
Result
$$\left(1+x^{2}\right)y''+xy'-a^{2}y=0\qquad\blacksquare$$

Level 4: Problems 16–20

Problem 16

LogarithmicHyperbolicExponential

Find the derivative. Look for a simplification before differentiating.

$$y=\ln\!\left(\frac{1+\tanh x}{1-\tanh x}\right)$$
Step-by-step solution
1

Multiply the numerator and denominator inside the logarithm by \(\cosh x\).

$$\frac{1+\tanh x}{1-\tanh x}=\frac{\cosh x+\sinh x}{\cosh x-\sinh x}$$
2

Use the exponential forms \(\cosh x+\sinh x=e^{x}\) and \(\cosh x-\sinh x=e^{-x}\).

$$\frac{e^{x}}{e^{-x}}=e^{2x}$$
3

The function is just a line.

$$y=\ln e^{2x}=2x$$
4

Check by differentiating directly, splitting the logarithm first.

$$y'=\frac{\operatorname{sech}^{2}x}{1+\tanh x}+\frac{\operatorname{sech}^{2}x}{1-\tanh x}=\frac{2\operatorname{sech}^{2}x}{1-\tanh^{2}x}=\frac{2\operatorname{sech}^{2}x}{\operatorname{sech}^{2}x}=2$$
Answer
$$\frac{dy}{dx}=2$$

Problem 17

Inverse hyperbolicLogarithmic

Find the derivative for \(x>0\), then identify \(y\) as a simpler function.

$$y=\tanh^{-1}\!\left(\frac{x^{2}-1}{x^{2}+1}\right)$$
Step-by-step solution
1

Let \(u\) be the inside. Use the quotient rule.

$$u=\frac{x^{2}-1}{x^{2}+1},\qquad u'=\frac{2x\left(x^{2}+1\right)-2x\left(x^{2}-1\right)}{\left(x^{2}+1\right)^{2}}=\frac{4x}{\left(x^{2}+1\right)^{2}}$$
2

Compute \(1-u^{2}\) using a difference of squares.

$$1-u^{2}=\frac{\left(x^{2}+1\right)^{2}-\left(x^{2}-1\right)^{2}}{\left(x^{2}+1\right)^{2}}=\frac{4x^{2}}{\left(x^{2}+1\right)^{2}}$$
3

Apply the inverse tanh rule.

$$\frac{dy}{dx}=\frac{u'}{1-u^{2}}=\frac{4x}{\left(x^{2}+1\right)^{2}}\cdot\frac{\left(x^{2}+1\right)^{2}}{4x^{2}}=\frac{1}{x}$$
4

A derivative of \(\frac1x\) means \(y=\ln x+C\). At \(x=1\), \(y=\tanh^{-1}0=0\), so \(C=0\).

$$y=\ln x$$
Answer
$$\frac{dy}{dx}=\frac{1}{x},\qquad y=\ln x\ \text{ for } x>0$$

Check with the log form \(\tanh^{-1}u=\tfrac12\ln\frac{1+u}{1-u}\). Here \(\frac{1+u}{1-u}=x^{2}\), so \(y=\tfrac12\ln x^{2}=\ln x\).

Problem 18

Inverse trigExponentialHyperbolic

Find the derivative and simplify to a single hyperbolic function.

$$y=\tan^{-1}\!\left(e^{x}\right)-\tan^{-1}\!\left(e^{-x}\right)$$
Step-by-step solution
1

Differentiate each term with the inverse tangent rule. The inside \(e^{-x}\) has derivative \(-e^{-x}\).

$$\frac{dy}{dx}=\frac{e^{x}}{1+e^{2x}}-\frac{-e^{-x}}{1+e^{-2x}}=\frac{e^{x}}{1+e^{2x}}+\frac{e^{-x}}{1+e^{-2x}}$$
2

Multiply the second fraction by \(\frac{e^{2x}}{e^{2x}}\). It becomes identical to the first.

$$\frac{e^{-x}\cdot e^{2x}}{\left(1+e^{-2x}\right)e^{2x}}=\frac{e^{x}}{e^{2x}+1}$$
3

Add, then divide the numerator and denominator by \(e^{x}\).

$$\frac{dy}{dx}=\frac{2e^{x}}{1+e^{2x}}=\frac{2}{e^{-x}+e^{x}}=\frac{1}{\cosh x}$$
Answer
$$\frac{dy}{dx}=\operatorname{sech}x$$

Same derivative as Problem 7. Since \(\tan^{-1}(e^{-x})=\frac{\pi}{2}-\tan^{-1}(e^{x})\), this \(y\) equals \(2\tan^{-1}(e^{x})-\frac{\pi}{2}\).

Problem 19

LogarithmicExponentialHyperbolic

Find the derivative for \(x\neq0\). The base of the logarithm is a function.

$$y=\log_{\cosh x}\!\left(e^{x}\right)$$
Step-by-step solution
1

A variable base has no direct rule. Convert to natural logarithms with the change-of-base formula.

$$y=\frac{\ln e^{x}}{\ln(\cosh x)}=\frac{x}{\ln(\cosh x)}$$
2

Use the quotient rule. From Problem 1, the denominator's derivative is \(\tanh x\).

$$f=x,\ \ f'=1\qquad g=\ln(\cosh x),\ \ g'=\tanh x$$
3

Apply \(\left(\frac fg\right)'=\frac{f'g-fg'}{g^{2}}\).

$$\frac{dy}{dx}=\frac{1\cdot\ln(\cosh x)-x\tanh x}{\left[\ln(\cosh x)\right]^{2}}$$
Answer
$$\frac{dy}{dx}=\frac{\ln(\cosh x)-x\tanh x}{\ln^{2}(\cosh x)}$$

The condition \(x\neq0\) keeps the base \(\cosh x\) away from 1, where the logarithm is undefined.

Problem 20

Inverse trigHyperbolicProof

Use derivatives to prove the identity for all real \(x\).

$$\sin^{-1}(\tanh x)=\tan^{-1}(\sinh x)$$
Step-by-step solution
1

Differentiate the left side with the inverse sine rule, using \(1-\tanh^{2}x=\operatorname{sech}^{2}x\).

$$\frac{d}{dx}\sin^{-1}(\tanh x)=\frac{\operatorname{sech}^{2}x}{\sqrt{1-\tanh^{2}x}}=\frac{\operatorname{sech}^{2}x}{\sqrt{\operatorname{sech}^{2}x}}=\frac{\operatorname{sech}^{2}x}{\operatorname{sech}x}=\operatorname{sech}x$$
2

The square root equals \(\operatorname{sech}x\), not its negative, because \(\operatorname{sech}x>0\) for every \(x\). The right side's derivative is also \(\operatorname{sech}x\), from Problem 7.

$$\frac{d}{dx}\tan^{-1}(\sinh x)=\operatorname{sech}x$$
3

Equal derivatives on an interval mean the two functions differ by a constant.

$$\sin^{-1}(\tanh x)-\tan^{-1}(\sinh x)=C$$
4

Find the constant by evaluating at \(x=0\).

$$C=\sin^{-1}(0)-\tan^{-1}(0)=0-0=0$$
Result
$$\sin^{-1}(\tanh x)=\tan^{-1}(\sinh x)\ \text{ for all real } x\qquad\blacksquare$$

Both sides are the Gudermannian function, which links ordinary and hyperbolic trigonometry. Problem 18's function is the same one written a third way.
